- Routed from smartmove-site (2026-09-23, minis): **two silent traps in `publications_manual.yml` entries.** (1) `authors` given as one comma-joined string (`"A, B, C"`) becomes a single author named "A, B, C" (`curation.py:40` wraps a string in a list), so no lab member is tracked, nothing is bolded, and the author filter misses the work, all at exit 0.
